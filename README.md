# Aurora Café ☕

Projeto desenvolvido como uma simulação de trabalho para um cliente, com o objetivo de criar um site institucional para a cafeteria fictícia Aurora Café.

## 📌 Sobre o projeto

O site apresenta informações sobre a empresa, seu cardápio e formas de contato, utilizando apenas HTML.

## 📄 Páginas

- Página Inicial
- Sobre nós
- Cardápio
- Contato

## 🛠️ Tecnologias utilizadas

- HTML5

## 🎯 Objetivo

Praticar a criação de páginas web, navegação entre páginas, formulários, tabelas, listas, imagens e estrutura semântica do HTML.
